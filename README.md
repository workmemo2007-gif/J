# محتوى موقع دايت فود

هذا المستودع هو مصدر محتوى الموقع `D1`. موقع GitHub Pages يقرأ الملف `menu.json` مباشرة عند فتح الصفحة؛ لذلك لا يحتاج تعديل HTML أو قاعدة بيانات D1 لتحديث أسماء الأصناف وأسعارها وأوصافها وصورها.

## بنية المحتوى

- `menu.json`: القائمة بصيغة JSON، وتتكون من `schemaVersion` و`menu`.
- كل قسم يحتوي `title` بالعربية والإنجليزية و`subCategories`.
- كل قسم فرعي يحتوي `title` و`dishes`.
- كل صنف يحتوي `id` و`name` و`desc` بلغتين، و`price` رقمياً، و`img` كرابط لصورة داخل هذا المستودع.
- `images/products/`: صور الأصناف.
- `images/brand/`: الشعار وصور الواجهة المستخدمة في الموقع.

تُظهر لوحة الإدارة معاينة قبل النشر ثم تنشئ commit في هذا المستودع؛ ويقرأ الموقع المنشور آخر نسخة من `menu.json`. يمكن تحديث الملف يدوياً أيضاً، بشرط الحفاظ على البنية السابقة وروابط الصور.

جميع الملفات هنا عامة لأن الموقع العام يحتاج إلى قراءتها؛ لا تضع كلمات مرور أو رموز وصول أو معلومات خاصة في هذا المستودع.
